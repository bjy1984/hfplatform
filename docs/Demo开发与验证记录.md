## 验证

- `pnpm build`：类型检查及生产打包。
- `pnpm test`：18项领域/状态测试，覆盖配额、库存失败、AB重复、快照、三审、多选判分、时间边界、字段过滤、角色限制、保存失败回滚、旧序号、交卷幂等、双评仲裁、阈值边界、三评及技能锁定。
- `pnpm test:e2e`：真实 Chromium 操作，9组流程；36角色入口渲染与横向溢出检查；命题→三审→入库；AB→冻结→配卷；考前检查→答题→刷新→失败重试→交卷；双评→仲裁；技能88分与390px布局；发布→回传失败→重试；题库和资料；Excel解析/重复拒绝/手工组卷。
- 浏览器测试输出：`test-results/e2e-results.json`；桌面工作台、答题页、阅卷、移动评分与投屏截图保存在同目录。测试会使用独立浏览器上下文重置其演示数据，不重置用户浏览器。
- 修复验证中发现的刷新答题被跳回工作台问题（等待初始路由就绪）、来源配额取整误差、去极值提前结算、答案存储失败误报保存等问题。

## 与原计划的差异及后续

1. 当前采用根目录单前端、自定义CSS、本地Pinia命令及localStorage，未采用apps/demo、Element Plus、IndexedDB、独立Mock HTTP服务。后续接真接口应先提取仓储与API适配层。
2. 六类题型可编辑；Excel仅客观题窄模板。富文本公式、媒体附件、Word、10余完整题型和通用附件中心后续实现。
3. 组卷比重暂为固定演示规则；手工选择自动均分，无自由排序、逐题改分、人工换题或复杂跨科目求解。
4. 有一个统一重置和六步导航引导，没有六套可切换快照。考试时间使用每份答卷开始时间+可推进偏移；正式场次权威时钟、真实迟到时间需由后端确定。
5. 名单、监考员为合成信息；名单导入、人员排班冲突和座位持久编排暂未开发。审批人与评委选择仅模拟，未实现组织回避和实名任务授权。
6. 签名为文本，不是原计划的手写示例。阅卷前端匿名不代表底层数据保密。多标签同步不包含并发写冲突解决。
7. 学习资料为3份自制文本，支持文本上传/发布/下载；未提供电子书版权资源、PDF阅读器。成绩档案导出JSON，未实现扫描纸卷上传及完整档案包。
8. 对外接口仅本地记录及状态变化；未连接人脸、SSO、HR、人社、考务系统。JSON备份可导出，无恢复导入；无正式灾备、密钥和加密设施。
9. 仅本机现代Chromium及尺寸检查，不代表真实移动设备、IE8、国产化、2000人并发、安全或协议全量验收。

后续优先：由甲方按角色确认流程字段与权限 → 确认组卷/评分/时间规则 → 接入服务端与真实身份权限 → 附件导入导出、多人协作、考务排场 → 外部联调及非功能验收。原需求追溯工作簿的134项功能、31项约束与协议范围继续保留。

## V0.3 目录树补全（2026-09-21）

- 将题库资源、知识结构管理的静态目录替换为同一份四级目录数据；命题编辑增加目录树选择器。旧版浏览器数据自动从题目及原知识点生成目录，不清空已有业务记录。
- 支持逐级展开/收起、全部展开/收起、名称搜索并显示祖先路径、任意层级筛选、后代题目计数、路径导航、URL选中节点和刷新恢复。树数量统计目录全部题目，右侧列表另外叠加题型/状态/来源筛选。
- 管理端可新增工种、等级、科目、知识点，同级名称去重；更名同步现有题目的对应分类字段并留痕，既有试卷快照不变；停用影响整条分支的新命题选择，保留历史检索；有子节点、现有题目或试卷引用的节点不能删除。
- 命题选择工种/等级/科目后，知识点联动过滤；目录树选择末级节点时一次填入完整路径。Excel新增题目可同步补入目录。
- 验证新增3项领域测试（总计21项），新增 `tests/trees.e2e.mjs` 覆盖展开搜索、分类筛选、刷新、维护与命题联动和390px布局。原9组主链浏览器验证继续保留。
- 当前仍为本地Mock目录；没有真实基础编码导入、拖拽迁移、跨节点批量合并或组织权限继承。
